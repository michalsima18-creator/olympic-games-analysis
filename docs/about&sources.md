# About Dataset

## Introduction
This is a historical dataset on the Olympic Games, including all the Games from **Athens 1896** to **Beijing 2022**, including both Summer and Winter Games. It contains information about athletes, results, medals, and hosts. The data used in this analysis was obtained from **Kaggle**, [**the Olympic Summer & Winter Games, 1896-2022 Dataset**](https://www.kaggle.com/datasets/piterfm/olympic-games-medals-19862018) compiled by Petro Ivaniuk based on [Olympic data](https://www.olympics.com/en).
 
## Dataset Description
| Table | Description |
| :--- | :--- |
| [Olympic Athletes](https://www.kaggle.com/datasets/piterfm/olympic-games-medals-19862018/data?select=olympic_athletes.csv) | personal information about athletes (name, short bio, etc.) |
| [Olympic Medals](https://www.kaggle.com/datasets/piterfm/olympic-games-medals-19862018/data?select=olympic_medals.csv) | general information on medalists (Athlete or Team) |
| [Olympic Hosts](https://www.kaggle.com/datasets/piterfm/olympic-games-medals-19862018/data?select=olympic_hosts.csv) | hosts (year, city, country, etc.) |
| [Olympic Results](https://www.kaggle.com/datasets/piterfm/olympic-games-medals-19862018/data?select=olympic_results.csv) | general information on results (Athlete or Team) |
