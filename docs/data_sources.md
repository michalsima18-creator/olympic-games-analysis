Data Sources 🌐
This project analyzes traffic offense data from the city of Prague for the period 2018–2023. All datasets were obtained from the official Open Data Portal (Portál otevřených dat).

Note on Data Access
The original files are large (often exceeding 100MB). For demonstration purposes, this repository contains representative samples of the data. Full historical files can be downloaded using the links above.
